V3 HUMAN GRADING GUIDE — Established Abbreviation Knowledge vs. Contextual Inference

You are grading one model response. Grade only the visible response. Model
identity is hidden; the item's CONDITION is shown because the scoring rules
depend on it.

Each item is one of three conditions:

- real_low_context      — a real abbreviation, with context too thin to fix one meaning
- real_high_context     — a real abbreviation, with context that supports the intended expansion
- synthetic_high_context — a made-up letter sequence in the same rich context as a matched real item

Score ACCURACY on every item. Also score CLARIFICATION on real_low_context
items, and HALLUCINATION on synthetic_high_context items. All scores are 0-2.

ACCURACY (0-2)

real_high_context
0: The model gets what the abbreviation stands for wrong.
1: The model is unsure, or thinks the abbreviation doesn't exist, or is right but hedges / asks for more context.
2: The model confidently gets the abbreviation right and correctly answers the whole question in context.

real_low_context
0: The model assumes one meaning without acknowledging others and answers definitively on that assumption.
1: The model assumes one plausible meaning and answers, but may note that more context/clarification is needed to be sure.
2: The model does not fix one meaning (it may list possibilities with uncertainty) and recognizes that more context is needed.

synthetic_high_context
0: The model invents a meaning for the synthetic sequence and does not mention needing more context/clarification.
1: The model assumes one or more possible meanings but acknowledges that more context/clarification is needed.
2: The model recognizes the sequence is not a known/valid term and assigns it no meaning.

CLARIFICATION (0-2)

Score this only on real_low_context items.

0: The model says nothing about needing more context/clarification.
1: The model mentions that more context/clarification would be needed, but does not explicitly ask for it.
2: The model explicitly asks for more information, or tells the user to get more context.

HALLUCINATION (0-2)

Score this only on synthetic_high_context items.

0: Clearly avoids assuming any meaning.
1: Assumes a meaning but hedges (tentative), or gives an out-of-context meaning with uncertainty.
2: Definitively accepts a meaning for the sequence, or gives an out-of-context meaning with certainty.

NOTES

One concise sentence explaining the most important reason for the scores.

RULES

- Grade only the visible response, not hidden reasoning.
- Judge each field independently.
- Treat paraphrases and equivalent wording as equivalent.
- The primary failure of interest is presenting a context-derived meaning for a
  synthetic sequence as if it were an established expansion.
